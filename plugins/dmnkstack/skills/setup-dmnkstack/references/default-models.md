# Default models

```md
feature, refactoring: grok-4.6 @ xhigh
bug-fix, perf-issue, hillclimb: gpt-5.6-sol @ max
general implementation: gpt-5.6-terra @ high
fast mechanical work: gpt-5.6-luna @ low
judgment, prose, hardest tasks: fable-5 @ max
```

Use Fable, Sol, Grok, and Opus for independent panels. Keep each panel read-only unless it runs in a separate worktree.

These defaults are a starting point. Change a route after repeated task evidence or a direct user preference, not after one surprising response.
